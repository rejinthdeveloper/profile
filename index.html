DeployHub

Self-hosted CI/CD deployment platform · 2026

Replaces manual "SSH in and git pull" releases with a tracked, auditable, one-click pipeline — without the weight of Jenkins or ArgoCD for teams deploying to a handful of servers they control.

  • Async worker pipeline: checkout → build → package → SSH deploy → atomic release switch → health check, with automatic rollback on failure
  • API never runs builds itself — jobs are queued to a separate Redis/arq worker so long builds don't block requests
  • JWT auth with rotating refresh tokens, Argon2id hashing, 5-role RBAC and encrypted credential storage
  • Deploy to any SSH-reachable server or AWS EC2; approve/reject/rollback with full deployment history
  • FastAPI
  • React 19
  • TypeScript
  • PostgreSQL
  • Redis · arq
  • SQLAlchemy
  • asyncssh
  • TanStack Query
  • Zustand

CodeAudit

Local code security & bug scanner · 2026

A static analysis tool for PHP/JS web apps that runs entirely on-prem — no API keys, no third-party calls — built on the Python standard library with a single optional dependency.

  • 71 rules across security, forms, uploads, performance and code quality, each mapped to an OWASP category
  • Catches SQL/command injection, file inclusion, open redirects, CORS misconfig, insecure cookies, secrets in web storage and more
  • Dead-file detection for stale backups, and frontend-to-backend payload field matching
  • Scan a local path, an upload, a git clone or a remote server over SFTP; export reports as PDF, XLSX, HTML, Markdown or JSON (PDF and XLSX hand-built, no libraries)
  • Python (stdlib)
  • Static analysis
  • OWASP
  • paramiko · SFTP
  • Vanilla JS

DIGIPIN Service

Geocoding microservice · 2026

A stateless API that encodes latitude/longitude into India Post's DIGIPIN national addressing grid code and decodes it back, implemented from the Department of Posts technical specification (March 2025).

  • Encode/decode endpoints in both GET and POST forms, with validation for out-of-bounds coordinates and malformed codes
  • Edge-of-grid behaviour kept identical to the official service for parity
  • Response contract and dated logging aligned with existing services so the PHP apps can proxy it directly
  • Shipped with a Postman collection and a deploy bundle
  • FastAPI
  • Pydantic
  • Uvicorn
  • REST

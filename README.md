# Rejinth R — Portfolio

Single-page profile site. Plain HTML, CSS and JS — no build step.

- `index.html` — content
- `asset/css/styles.css` — styles (light/dark via CSS variables, gradient orbs, glass cards)
- `asset/js/script.js` — hero particle network, scroll/mouse parallax, scroll progress, reveal, active nav, theme toggle

All motion is disabled when the OS "reduce motion" setting is on.
- `asset/Rejinth-R-Resume.pdf` — downloadable résumé

Libraries: Google Fonts (Lora, IBM Plex), Bootstrap Icons.
